# Bannerlator 1.0

Run Windows apps and games on Android — no PC and no root required.

**WinHub 1.0 is about controllers, the HUD and OpenGL.** A brand new controller engine (Hermes) with real hot-plug, rumble and Direct XInput, a rebuilt Fusion HUD, Fast OpenGL through Mesa + Zink, a Sync selector, a Music Player and a lot of portrait and Deck polish.

<!-- update-summary: WinHub 1.0: the Hermes controller engine with Direct XInput, a rebuilt Fusion HUD, Fast OpenGL, a Sync selector, a Music Player and portrait and Deck polish. -->

> ⚠️ **Hermes and Fast OpenGL are new in this release.** If a controller or an OpenGL game misbehaves, turn the setting off for that container or game and report it.

# What's New — everything since 0.1

## 🎮 Hermes controller engine

A new way to get your controller into the game, replacing the old shared-memory ring.

- 🪽 One fixed-size shared state file per player slot. A button pressed and released between two reads is still delivered, both the press and the release.
- 🔌 Real hot-plug, live reconnect of held slots, and the on-screen pad is seated before Wine boots.
- 🆔 Per-slot controller identity and DirectInput force feedback.
- 🧩 **Direct XInput:** replacement `xinput` DLLs (x86_64, i386, ARM64X) per container, with in-game switching and rumble.
- 🕐 Stick updates paced to the game's frame rate: Auto, Fixed or Unpaced.
- 🧪 New **Controls → Pad** tab in the in-game menu, and a **Controller input** log in the Log Manager.
- 🔀 *Enable XInput*, *Enable DInput* and *Exclusive Input* became one switch: **"DirectInput games can see the controller"**. Old data reads the same.
- 🆕 New containers start with Direct XInput on and the DirectInput switch off. Existing containers keep their own settings.

> ⚠️ New in 1.0. Please report controller problems.

## 📊 Fusion HUD, rebuilt

- 🧱 Four Steam Deck style levels: FPS, + frametime graph, + GPU/CPU/memory, everything.
- 🎨 MangoHud colours, a big FPS number that turns amber and red as it drops, per-core bars.
- ⏱️ Level 4 shows a **PRES** row (present latency and skipped frames) while SurfaceDirect runs.
- 🗑️ The Classic, GameHub and GameNative HUDs are gone. A saved HUD style of another value becomes Fusion. New containers start at level 2.

## 🚀 Fast OpenGL

- OpenGL games present through the bundled Mesa + Zink over a Vulkan swapchain instead of a readback on every frame.
- EGL layers take the EGL route. Others use a new opt-in server-side GLX.
- **Show FPS** and **Vsync off** switches sit beside it, in the container editors and as Auto / On / Off per game.

> ⚠️ New in 1.0. The GLX route is opt-in.

## ⏲️ Sync selector

Choose **esync, ntsync, fsync or wineserver** per container, or per game. Options the Wine layer cannot run are greyed out and fall back to the layer default.

## 🎵 Music Player

Settings → General: pick an MP3 and play it in the app. A separate **Play in games** switch is off by default. It loops, pauses when the app leaves the screen and takes no audio focus.

## 📱 Portrait and Deck polish

- 🌊 Liquid waves on Storage, Files, Controls, Contents, Saves, Social Hub, Settings and Stores. Drifting glows stay on Home.
- 🏷️ A store logo or folder badge on each game cover.
- 🌫️ Content fades out above the bottom bar instead of a hard cut.
- 🃏 The classic game menu and small Contents dialogs are centered rounded cards.
- ✏️ Text fields get a full rounded outline, with symmetric margins on text rows and Env Var values.

## 🔧 Smaller

- 🛠️ Fixed a compile error in the GLX extension and a missing brace in the on-screen pad seating.
- 🚫 No wave backdrop behind the per-game settings editor.
- 📖 README rewritten for WinHub, version bumped to 1.0 (`versionCode 90`).

## ⚠️ Carried over — still open

- Nothing from 0.1-beta is known to be fixed by this release. The new Hermes controller engine and Fast OpenGL have had limited testing, so treat them as the likeliest places to find bugs.

# Bannerlator 2.0

Run Windows apps and games on Android — no PC and no root required.

**WinHub 2.0 is plug and play.** Add a game and play it, with nothing to configure. If a game crashes, Game Doctor finds the cause and fixes it for you. This release also brings a new Deck Home with two styles, a Glass interface look, a retro library, the Wayland display path, GE-Proton based container defaults, per-stick controller tuning, Ubisoft Connect support and a rebuilt first-run setup.

# What's New — everything since 1.2

## Plug and play

- **Nothing to set up first.** First run installs GE-Proton 11.0-9 (arm64ec) and the setup wizard picks the right driver for your device, including a HyperOS / One UI step.
- **Adding a game takes one step.** WinHub reads the game and fills in its name, app ID and cover art.
- **Tested defaults for every new container:** the latest GE-Proton, a Turnip matched to your chip, DXVK 2.4.1 gplasync, Performance FEX, a 1600x720 screen, and Wayland wherever the layer supports it. The Simple view shows only the settings most games need; Advanced still has everything.
- **Store launchers set themselves up** with a one-time prompt instead of an error, and the game starts by itself when the setup is done.
- **When a game crashes, Game Doctor handles it.** It reads the game's logs, lists what it found and fixes it in one tap, with undo. With Auto step-down (on by default), a game that crashes soon after launch from a CPU-translation fault is moved one FEX preset safer on its own, and you get a notice with undo.

## Home

Deck Home has two styles, chosen in Settings and in the first-run setup.

- **Steam Home** (look by AbuNashmi): a covers row along the bottom and a tabs page for Stores, Downloads, Friends and Social. One shelf per store (Steam, Epic, GOG, Amazon), an Add game card, and an All Games card with a drifting wall of your covers behind it.
- **Full XMB Home:** Stores and Social cards in the XMB layout, a Social Hub page, larger glowing Home cards and a smoother dropdown.
- **Game settings from Home:** choose whether a game's Settings opens the Classic page (on glass over the game's blurred art) or the XMB columns.
- **Launch menu:** a three-column card in landscape.
- **Store pages:** a landscape XMB game page with full-bleed art for Steam, GOG, Epic and Amazon.
- **Sounds:** SteamOS-style navigation sounds, with a choice in Settings.
- File Manager redesigned, driver / DXVK / VKD3D / FEX chips on Storage cards, and an optional launcher icon that follows the theme.

## Interface look: Glass and Material

A new Interface look setting applies to every Deck page, the Steam pages and a game's settings. Glass puts the stores, Storage, Files, Contents, Save Manager and Controls on frosted glass over the blurred art of the last focused game, and starts on the new Charcoal theme. The default theme stays Marcescence.

## Retro library

A retro library sits beside the PC library, switched with a chip (Select on a pad). 109 consoles and 47 emulators, one row of every game of the consoles you picked, covers and backgrounds from SteamGridDB, and a game's options in the same XMB dropdown as the PC Home. Also in portrait.

## Game Doctor

Game Doctor reads a game's last run logs, checks its settings against your device, looks up shared configs and turns that into plain findings with one-tap fixes and undo. It is on Deck Home, the portrait sheet, classic cards, the Games wall and Big Picture.

- Input fixes: exclusive input, DirectInput off, XInput off.
- A Wayland pacing finding with a one-tap Smooth adapter profile.
- Auto step-down: only the FEX preset, only for that game, and it can be undone.
- The Configs tab can browse the curated config library by game.

## Wayland display path

The embedded Wayland display path is back, built by The412Banner.

- A Display backend picker in the container, shortcut and XMB game editors.
- Mali (PanVK) mode and a Mali System compositor driver choice. The picker offers only drivers the compositor can use.
- Adapter settings in the Deck style, with profiles and a background-generated adapter report.
- HDR10 output on screens that support it, cursor auto-hide, and Wayland session logs in the log viewer.
- A container's first Wayland launch asks before it starts.

## Container defaults and components

- The Deck offers newer GE-Proton, with an optional switch of existing containers. The Updater tab lists Proton, driver and FEXCore with what is installed and what is newest.
- A Simple / Advanced switch in the container editor. Simple shows Proton, screen size, display backend, DXVK, driver and FEXCore preset.
- The defaults editor is filled with the app's own defaults and has a reset button.

## Controls

- Per-stick deadzone and sensitivity, with a per-game override, in the XMB game settings and the in-game drawer.
- On-screen control icon styles: Fusion (the new default), Glass and Neon.
- The Fusion HUD gets a neon outline, the WinHub mark and theme-tinted text.

## Ubisoft Connect support

Ubisoft-published Steam games and Epic builds of Ubisoft games are detected. The first launch in a container offers a one-time Ubisoft Connect setup, using the game's bundled installer or Ubisoft's own installer downloaded after you agree. The Ubisoft overlay is turned off because it crashes games on an Arm64EC DXVK, Epic installs are registered so Connect does not offer to download them again, and Log Manager gets an opt-in Ubisoft diagnostics report.

## First-run setup and loading screens

- The first-run wizard is fullscreen, fits portrait, and adds steps for Home, Sounds, Stores sign-in and a HyperOS / One UI driver.
- The launch screens play the animated WinHub mark, and the Starting services screen is a glass card with store logos and an overall progress bar.

## Removed

- The Classic Home style. Steam Home and Full XMB Home replace it.
- The "Apply layout everywhere" switch. Save Manager and Contents follow the Settings layout.

## 🔧 Smaller

- Version 2.0, versionCode 93.
- Landscape cutout bar and rail icons fixed, B reliably returns on Steam Home, and the Simple settings page no longer crashes the container editor before it has loaded.

## ⚠️ Carried over — still open

- Ubisoft Connect support has not been tested on a device yet. If a Ubisoft game misbehaves, turn on the Ubisoft diagnostics report in Log Manager and send the report.

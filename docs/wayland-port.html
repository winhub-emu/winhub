Wayland in WinHub

The embedded Wayland display path, back in WinHub on branch rm-wayland-linux.

Status

  • Not built, run or tested yet. Build once and try one Wayland game launch.
  • Wine runs through winewayland into the embedded compositor instead of the Java X server.

What is included

  • Native compositor waylandcomp (Vulkan present, effects chain, HDR, frame generation bridge, clipboard, text input, pointer lock).
  • WaylandDisplayActivity, wayland/*, WaylandHdr, WineWaylandSupport.
  • Wayland game driver, imported driver manager, and the Wayland adapter with its settings and driver probe.
  • Session code merged into XServerDisplayActivity: pointer-lock warp filter, bring-to-front, touch cancel, per-game Wayland logs.
  • Editors: container, shortcut and XMB game settings with Wayland driver, adapter dialog, HDR, and Fast OpenGL locked on.
  • Contents: Wayland game driver import list.

Not included

  • proot, gamescope and the Linux runtime.
  • yserver, the guest keyboard typer, Mali PanVK mode.
  • Win-FG training capture, Unreal Engine HDR, Bionic-FG options.

Controller

  • New settings rows are reachable with D-pad and A/B in the shortcut editor (the advanced fold and the adapter gear are focusable).

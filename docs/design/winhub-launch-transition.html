New part (not in the app yet): after the fill, three circles centred on the mark's three dots shrink from covering the whole screen down to the dot size, easing cubic-bezier(.2,.5,.3,.9) so the blue spends most of its time turning into the dots; the rest of the mark and the text fade in as they settle. In the app this is three drawCircle calls and one radius value.

How it ports to the app 
// PreloaderOverlayHelper.playReveal: replaces "scale the sheet to 0"
// phase = 0..1 over MORPH_MS (520), driven by Animatable + tween(MORPH_MS, CubicBezierEasing(.2f, .5f, .3f, .9f))
val r0 = hypot(size.width, size.height)        // one circle alone covers the screen
val dotR = DOT_R * markScale                   // the mark's own dot radius in px
val r = r0 * (dotR / r0).pow(phase)            // geometric: even to the eye
for (c in dotCentres) drawCircle(Blue, r, c)   // the union is the blue that is left
// phase == 1: the circles are exactly the mark's dots, so drawing stops
// and WinHubLogoAnimation takes over (its loop starts at t = 0).
